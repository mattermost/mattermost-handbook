# Localization

Mattermost translations are generated and maintained through an AI-driven pipeline that keeps supported languages fully up to date with every monthly release.

This page explains how the pipeline works and how language experts can contribute.

## How translations work now

Starting with Mattermost v12.0 (October 2026), translations are generated by an automated pipeline rather than manual contribution on Weblate. Here's how the end-to-end flow works:

1. **Source strings are updated in the codebase.** When Mattermost Engineering merges a pull request that adds or modifies US English strings, those changes are the input to the translation pipeline.
2. **The AI pipeline generates translations.** After code complete for the upcoming release, the pipeline produces translations for supported languages for all changed or new strings. The pipeline is informed by [glossary files](https://github.com/mattermost/mattermost/tree/master/i18n/glossary) that define how Mattermost-specific terminology should be rendered in each language.
3. **A pull request is opened automatically.** The pipeline opens a PR to the relevant GitHub repositories ([mattermost](https://github.com/mattermost/mattermost), [mattermost-mobile](https://github.com/mattermost/mattermost-mobile), [desktop](https://github.com/mattermost/desktop)) containing the updated translation files for all languages.
4. **PRs are reviewed and merged on the release cadence.** Mattermost Engineering reviews the PRs for consistency and merges them into the main branch ahead of each release.

## Supported languages

Users may change their language preference in **Settings > Display > Language**. The following 23 languages are officially supported:

Bulgarian, Chinese (Simplified), Chinese (Traditional), Danish, Dutch, English (Australia), English (US), French, German, Hungarian, Italian, Japanese, Korean, Persian, Polish, Portuguese (Brazil), Romanian, Russian, Spanish, Swedish, Turkish, Ukrainian, Vietnamese.

## Experimental languages

Users can also select from a range of experimental languages, including:

Belarusian, Croatian, Czech, Finnish, Lithuanian, Norwegian Bokmål, and Portuguese (Portugal).

Experimental languages require validation from a language expert before being promoted. If you are a native speaker of an experimental language and would like to help promote it to officially supported status, please reach out in the [~i18n channel](https://community.mattermost.com/core/channels/localization) on our Community server or contact your Mattermost account manager.

**Note:** Starting with Mattermost Server v12.0 (October 2026), the `LocalizationSettings.EnableExperimentalLocales` configuration setting has been removed, along with several experimental language catalogs that contained low usable translation coverage.

## How to contribute

Human language expertise remains valuable and necessary to verify the output of the pipeline. While Weblate is no longer used for submitting translations, there are two meaningful ways to stay involved:

### 1. Monthly diff review

Each month, review the diff for your language's JSON file in GitHub. If you spot inaccuracies, submit a pull request directly to the repository.

* [mattermost/mattermost](https://github.com/mattermost/mattermost/tree/master/server/i18n) — `server/i18n/<lang>.json`
* [mattermost/mattermost-mobile](https://github.com/mattermost/mattermost-mobile/tree/main/assets/base/i18n) — `assets/base/i18n/<lang>.json`
* [mattermost/desktop](https://github.com/mattermost/desktop/tree/master/i18n) — `i18n/<lang>.json`

When submitting a PR, target the `master` branch and describe the inaccuracy you're correcting and the preferred phrasing, with brief reasoning where helpful.

### 2. Glossary maintenance

[Glossary files](https://github.com/mattermost/mattermost/tree/master/i18n/glossary) define how Mattermost-specific terms are translated. Getting these right has an outsized effect on AI translation quality across the board. If you are knowledgeable in a supported language, helping maintain its glossary file is one of the highest-impact contributions you can make.

## Questions and feedback

Join the conversation in the [~i18n channel](https://community.mattermost.com/core/channels/localization) on the Mattermost Community server.

Language-specific channels are also active — examples include [~i18n-german](https://community.mattermost.com/core/channels/i18n-german), [~i18n-french](https://community.mattermost.com/core/channels/i18n-french), and [~i18n-swedish](https://community.mattermost.com/core/channels/i18n-swedish).
